# Lyra 商业模式与运营方案(个人创业训练版)

> 姊妹文档:[`promotion-strategy.md`](./promotion-strategy.md)

## 0. 前提改写

三条约束,决定了整份文档的取舍:

1. **总预算 ¥5000**(个人自掏,不融资)
2. **无盈利目标,回本即可**
3. **真正的收益:训练自己的创业能力 + 运营一个自负盈亏的小工具**

这三条一起意味着:

- 这不是一个「startup」,是一个 **micro-solo project**(Tyler Tringas / Nathan Barry / MicroConf 那个赛道)。
- 决策上最贵的资源不是钱,是**你的注意力**和**Lyra 的品牌纯度**。任何伤到这两样的机会,即使能带来收入,都要拒绝。
- 因为「回本」的门槛极低(下文算过,¥1500/年),所以定价决策的第一目标 **不是收多少钱,而是选一种让你学到最多的收费方式**。

## 1. 三年成本模型

固定支出(必付):

| 项目 | 年成本(RMB) | 备注 |
|---|---|---|
| Apple Developer 账号 | ~¥700 | $99/年,发行 macOS 必需 |
| 域名 | ~¥60 | .com 或 .app,一个就够 |
| 代码签名 / 公证 | ¥0 | Mac 端 Apple Dev 已含;Windows 暂不做 |
| 邮箱 / 域名邮件 | ~¥100 | 或用 Gmail 免费 |
| **年度小计** | **~¥860** | |

弹性支出(可选,建议先不花):

| 项目 | 一次性 / 年 | 立场 |
|---|---|---|
| 官网托管 | ¥0 | 用 GitHub Pages / Cloudflare Pages 免费 |
| Analytics | ¥0 | Plausible 免费自建,或直接不装 |
| 社群 | ¥0 | 用 Discord 免费版或飞书群 |
| 广告 | ¥0 | 明确不投,任何一分都不投 |
| 视频拍摄/剪辑软件 | ¥0 | Final Cut 试用期够用,或 CapCut |
| 一次高质量品牌图/字体 | ~¥300 | 唯一值得花的"审美投资" |

**三年总支出**:¥860 × 3 + ¥300(品牌一次性) + ¥1500(预留:bug 应急、印一本小册、报名一次 MicroConf 会员) = **~¥4380 / ¥5000**

结论:**¥5000 预算足以让 Lyra 无收入运转 3 年**。这是最重要的心理安全垫 —— 你不会因为缺钱而做出伤 Lyra 品牌的决策。

## 2. 回本数学

年成本 ~¥900。三种模式下的回本人数:

| 模式 | 单价 | 回本用户数(年) | 隐含风险 |
|---|---|---|---|
| 一次性买断 | ¥58 | ~16 位/年,**每年都要重新获客** | 获客压力驱动品牌降级 |
| 一次性买断 | ¥128 | ~7 位/年 | 定价偏高对种子期不友好 |
| Patron 月费 | ¥15/月 | **~5 位稳定订阅即回本** | 需要月更内容维持 |
| Patron 月费 | ¥25/月 | ~3 位稳定订阅即回本 | 更高的价值承诺 |

**Patron ¥15/月 是最优解**。原因:

- 5 个稳态用户就回本 —— 这在你的种子 10 人计划里几乎是必然结果。
- 定价便宜到"一杯咖啡",拒绝会有心理成本,续订阻力最小。
- 月度触点意味着**每个月都有一次和用户对话的自然理由**,这是创业训练的核心资产。
- 不需要持续做新增,能把注意力留给产品本身。

## 3. 推荐路径:Patron-first(而非 buyout-first)

### 3.1 产品结构

- **App 本身**:免费下载,BYOK(用户自带 LLM API key)。
  - 免费 = Lyra 的灵魂不被"付费墙"污染。
  - BYOK = 你不承担 token 成本,零边际成本。这是这个模式能成立的技术前提。
- **Patron 会员("Lyra Letters")**:¥15/月 或 ¥150/年(年付 8.3 折,鼓励长期承诺)。
  - **限额 100 人**。写进 landing page。人数上限本身就是营销文案。

### 3.2 Patron 到底在卖什么

不是"App 的附加功能" —— 那样一旦 App 更新完,会员就没理由续订。

卖的是**作者的持续在场** + **一段小群关系**。具体承诺(每月至少交付其一,理想都做到):

- **月度作者信**:一封由**你(不是 Lyra)**写给会员群的信。内容可以是:这个月我改了 Lyra 的哪一处、我为什么这样改、我最近听到的一张专辑、一段和某位匿名用户的对话。~800-1500 字。
- **Lyra 的月度片段**:精选一段 Lyra 主动写给某个用户(经该用户匿名同意)的信,附上你的注释。这是极强的"内容资产 + 二次传播物料"。
- **会员先看 / 会员投票**:下一个大版本的方向,让会员在两三个选项里投票。**投票不是民主,是仪式**,让人有归属感。
- **半年一次的线上小型听音乐夜**:Discord / 飞书 45 分钟,你放歌 + 大家聊天。**这是留存的秘密武器**,一次到场率 30% 都够用。

### 3.3 不做的事

- **不做团队版 / 企业版**。这个赛道的团队定价会毁掉 Lyra 的"私人物件"感。
- **不接广告 / 不接品牌合作**。哪怕是"契合"的合作,都会稀释品牌纯度。
- **不做云同步作为付费卖点**。局限于本地是 Lyra 的立场,不是缺陷。要把这个立场卖成资产。
- **不做免费试用期 / 折扣券 / 首月优惠**。Lyra 的品牌里不该有"促销"这个动作。原价即最低价。

## 4. 前 12 个月运营节奏

按季度看,不按周,避免管理疲劳。

### Q1(月 1-3):不收费,只筛人

- 执行 `promotion-strategy.md` 的 W1-W8。
- **完全不提 Patron 的存在**。这是筛选期,任何付费信号都会污染动机纯度。
- 目标:招募到 10-15 位真种子用户。定义:能说清自己为什么需要 Lyra 的人。
- 每周:**和至少 1 位种子用户做一次 30 分钟对话**(文字 / 语音 / 见面均可)。这是本阶段唯一的 KPI。

### Q2(月 4-6):把 Patron 铺出来,不推销

- 月 4:上线 Patron 页面,但**不发正式营销**。只在 GitHub README、个人 Blog 页脚、X 主页 bio 里加一句「Support Lyra: [link]」。让**想找的人自己找到**。
- 月 4 底:发第一封月度作者信。**即使当时只有 0 个 Patron,也写,也公开首封**。第一封公开信本身是最好的招募文案。
- 月 5-6 观察:哪些人自发订阅?他们是哪一类种子?他们订阅前的最后一次触点是什么?
- 目标:**5 位 Patron**(=回本)。到不了也没关系,重要的是数据。

### Q3(月 7-9):把学到的东西拧成第一次迭代

- 用 Q1-Q2 攒下的对话,做一次产品迭代。**不追加功能,而是删减和精修**。
- Patron 内容节奏稳住:每月一封信 + 一段 Lyra 片段。
- 第 8 个月:办一次线上听音乐夜(即使只有 3 个人来)。这次的手感极重要。
- 目标:**10 位 Patron**。到这里你已经"运营着一个自负盈亏的小工具"。

### Q4(月 10-12):做一次"结账"

- 写一篇公开的年终复盘(发 Blog + X + Patron 信)。诚实交代:多少下载、多少 Patron、多少收入、多少支出、学到什么。
- **这篇复盘是最好的第二次招募材料**。透明本身是稀缺资产。
- 决策点:如果 Patron ≥ 10,继续按现状滚一年。如果 < 5,回头审视是**产品**还是**触达**的问题(下一节详说)。

## 5. 该花钱的地方 & 该拒绝的地方

### 该花(¥5000 内)

| 项目 | 预算 | 时机 |
|---|---|---|
| Apple Dev 三年 | ¥2100 | Q1、Y2 初、Y3 初 |
| 域名三年 | ¥180 | Q1 |
| 一次高质量品牌视觉(logo / hero) | ¥300 | Q1 |
| MicroConf / Indie Hackers 一次线下或会员 | ¥500-800 | Y2 |
| 印 100 本小册子(Lyra 精选信)当礼物 | ¥800 | Y2 底 |
| 预留应急 | ¥600+ | 一直有 |

### 该拒绝

- **任何形式的广告投放**。信息流、Google Ads、播客口播、KOL 合作,一律不做。
- **付费工具订阅**。Notion Pro、Figma Pro、Analytics 付费版、任何 SaaS 月费。用免费替代或不用。
- **付费社群 / 大师课**。绝大多数不值。想学 solo micro-SaaS,读免费的东西就够(Tyler Tringas《Start Small, Stay Small》、Nathan Barry 的博客、Justin Jackson 的 MegaMaker 播客)。
- **外包设计 / 外包运营**。这就是你要训练的东西,外包等于把学习机会花钱送走。

## 6. 训练创业能力的 KPI(非营收)

营收 KPI 是"结果指标",作为创业训练目标它反馈太慢。真正该盯的是**过程指标**,反映你有没有在正确地练习:

| KPI | 目标 | 为什么 |
|---|---|---|
| **每周深度用户对话** | ≥ 1 次,30 分钟以上 | 客户发现是 solo 创业最贵的能力 |
| **月度作者信按时发出率** | 100%(哪怕 0 订阅) | 承诺兑付是品牌信任的根 |
| **每月拒绝的合作 / 功能请求数** | ≥ 1 | 说"不"是产品经理的核心技能 |
| **每季度公开一次复盘** | 4 次 / 年 | build in public 的品牌复利 |
| **年度总支出** | ≤ ¥1500 | 财务纪律训练 |
| **Patron 30 天留存率** | ≥ 80% | 唯一比新增更重要的数字 |

**故意不列的 KPI**:下载量、GitHub star、Twitter follower、日活。这些是虚荣指标,会诱导你为了它们做错误的动作。

## 7. 三个可能的失败模式 & 预警信号

写这一节是为了以后你翻回来的时候有一面镜子。

### 失败模式 A:「无人问津」

- 预警信号:Q1 结束时,深度对话触达 < 3 人;GitHub 无自然流入 star;Blog 长文阅读 < 200。
- 诊断:**触达问题**,不是产品问题。
- 应对:不加预算,加时间。再压一次 Blog 长文 + 一次 Show HN,把 promotion-strategy.md 的 X build-in-public 节奏拉长到 12 个月,不缩短。**耐心是这条赛道的护城河**。

### 失败模式 B:「有人下载,没人付费」

- 预警信号:Q2 结束时,活跃用户 ≥ 20 人,但 Patron 0-1 个。
- 诊断:**价值主张问题**。你没把「作者的持续在场」这个东西讲清楚,或者你自己每月的内容还不够诱人。
- 应对:不降价,不搞折扣。**把作者信的质量提上去**,让一封信本身好到能被截图转发。同时和已有活跃用户直接聊一次:如果 Lyra 明年停更,你会难过吗?他们的回答会告诉你到底缺什么。

### 失败模式 C:「用户来了不留」

- 预警信号:Patron 30 天留存 < 60%;下载后 7 天使用率 < 30%。
- 诊断:**产品问题**,Lyra 本身没有 hook。
- 应对:回到产品。这里没有商业模式能救的问题。看看是不是"周信"「情感状态」这类核心 loop 没跑通,或者交互门槛太高。**这是唯一值得把预算重投到产品改进上的情况**。

## 8. 一条底层判断线

每次做商业决策(定价 / 合作 / 上功能 / 发内容)之前,问自己两句:

1. **这个决策会让我更接近"运营一个自负盈亏的小工具"这个目标,还是让我更接近"一个尴尬的中间形态"?**
2. **这个决策五年后我会不会觉得掉品?** 如果会,再赚钱也不做。

Lyra 不是拿来赚钱的,它是拿来证明**你能在克制和诚实中,建成一件长期属于你自己的作品**。¥5000 的预算天花板,恰好是这份修行的护栏。
