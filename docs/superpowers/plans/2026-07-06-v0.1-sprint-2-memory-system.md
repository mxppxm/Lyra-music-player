# v0.1 Sprint 2 — Memory System Implementation Plan

> **For agentic workers:** Use superpowers:subagent-driven-development to dispatch implementers per task. **Reviewer step is skipped by user's directive for Sprint 2 — implementer TDD + typecheck gates are the SDD gate.**

**Goal:** Turn Lyra from "answers with a song" into "remembers you." After Sprint 2: every turn is inspected for significance and lands in `shared_memory` + `memory.md` if it stands out; a manual **Reflect now** button (or `Cmd+Shift+R`) triggers a single deep-reflection LLM call that updates the Living Portrait, adjusts the Facts library confidences, and writes a Dream narrative. On next launch, Lyra's CompanionAgent reads the Living Portrait + top facts into its system context — so she visibly knows you a little better each time.

**Architecture:** New TS modules under `src/memory/` (file layer + parser/serializer + reader) and `src/reflect/` (agent + trigger). Rust side gains one command for the app-data directory. HomeView + Settings get minimal additions (Reflect button, Cmd+Shift+R keybinding, small "dreaming…" overlay). No new agent orchestration beyond the single-call `ReflectAgent`.

**Tech Stack:** No new frameworks. Rust: `dirs = "5"` for app-data resolution (or reuse Tauri's `path::app_data_dir()` — recommended, no new dep). TS: keep the existing stack.

## Global Constraints

- **Tauri 2.x**, Rust 1.75+, pnpm 8+, Node 20+
- **Commit prefix `feat(lyra):` or `fix(lyra):`**
- **New modules < 250 lines**
- **memory.md path** is `<tauri app data dir>/memory.md` — same folder as `lyra.db`. On macOS: `~/Library/Application Support/com.daoyu.lyra/memory.md`
- **User-edited memory.md wins over agent state** for the Living Portrait section. Fact updates from Reflect are additive/incremental — never delete a fact from Facts on Reflect; only add/adjust conf/n
- **Reflect uses CompanionAgent's provider by default** (Claude Opus), fallback Zhipu. It's a big-context task; the plan calls out `max_tokens: 4096`
- **No memory.md content is streamed to the LLM in raw form** in the CompanionAgent prompt during a normal turn — that's a Sprint 3+ optimization. Sprint 2 injects a compressed snapshot (top 5 facts by n × conf + Living Portrait) into system context on boot
- **All LLM outputs from ReflectAgent MUST parse as strict JSON**; fallback: skip Reflect with a user-visible error rather than partial-apply
- **Every task ends with `pnpm test` + `pnpm typecheck` green** before commit
- **Reviewer step skipped per user directive** — the implementer's TDD evidence, test count, and typecheck are the gate. Any implementer's DONE_WITH_CONCERNS must be surfaced to the user immediately

## Task 2: Salient Moments Detector

**Files:**
- Create: `app/src/moments/salient.ts` + `.test.ts`

### Interface

```typescript
import type { DialogueTurn, LibraryTrack } from "../types";
import type { SalientMoment } from "../memory/types";

export type SalientContext = {
  turn: DialogueTurn;
  song: LibraryTrack;
  currentTags?: string[];   // e.g. ["#时段:深夜"] — supplied by orchestrator based on time-of-day
};

export function detectSalientMoment(ctx: SalientContext): SalientMoment | null;
```

### Rules (all no-LLM)

1. **Silent full listen (positive anchor)**
   - `turn.user_reaction.silence_positive === true`
   - `turn.user_reaction.behavioral.completed === true`
   - `song.duration_ms && turn.user_reaction.behavioral.listen_duration_ms >= 0.9 * song.duration_ms`
   - → Significant with narrative `"《{title}》完整听完，沉默正向。"`

2. **Explicit positive verbal**
   - `turn.user_reaction.verbal?.parsed_valence === "positive"`
   - → Significant with narrative `"《{title}》你说：{verbal.content}"`

3. **Repeated listen (strong love)**
   - `turn.user_reaction.behavioral.repeated >= 2`
   - → Significant with narrative `"《{title}》你重听了 {repeated+1} 次。"`

4. **Explicit rejection (negative anchor)**
   - `turn.user_reaction.behavioral.skipped === true`
   - `turn.user_reaction.verbal?.parsed_valence === "negative"`
   - → Significant with narrative `"《{title}》被你拒绝：{verbal.content}"`

If multiple rules fire, pick the highest-priority in order: Repeated > Silent > Explicit positive > Rejection. Only produce one moment per turn.

Tags default from `ctx.currentTags` (orchestrator will fill from time-of-day / weather when available; for v0.1 β, orchestrator supplies `["#时段:深夜"]` etc. based on `new Date().getHours()`).

### Reflect prompt (中文, verbatim in prompt.ts)

```
你是 Lyra 的反思核心。用户手动触发了一次 Reflect —— 你要回望她最近一段时间和你的每一次对话，
把感受沉淀成三样东西：

  1. 更新她的 Living Portrait —— 一段 2-4 段的、写给她自己看的画像。要有具象，不要标签堆砌。
  2. Facts 库的调整 —— 你发现的新条件偏好 / 已有偏好的加强或削弱。
  3. 一段"梦" —— 你昨夜在做的反思，语气偏散文，不长，两三句话就够。

我会给你四份材料:
- todayISO
- 最近的对话回合(包括她说的话、你选的歌、她的反应、当时的情绪)
- 已有的 Facts 库(带 conf 和 n)
- 已有的 Living Portrait

请以 STRICT JSON 返回，形如:

{
  "livingPortrait": "两到四段中文，写给她的画像",
  "factMutations": [
    { "op": "add", "tags": ["#时段:深夜", "#状态:疲惫"], "conclusion": "慢速古典钢琴", "startConfidence": 0.5 },
    { "op": "increment", "tags": ["#天气:雨天"], "conclusion": "环境音乐", "deltaN": 1 },
    { "op": "adjust", "tags": ["#活动:通勤"], "conclusion": "独立摇滚", "newConfidence": 0.4 }
  ],
  "dreamNarrative": "一段中文散文,50-150 字"
}

原则:
- 不确定的观察就不写。宁少勿多。
- Living Portrait 要写"她是什么样的人"、"她最近在什么状态"，不写"她喜欢什么歌"（那是 Facts 的活）。
- factMutations 里的 conclusion 要具象("慢速古典钢琴"),不能是"平静的音乐"这种废话。
- Dream 是你回望后剩下的味道,不是流水账。

不要在 JSON 前后加任何文本。不要用 markdown。
```

### apply.ts logic

- **Living Portrait**: overwrite `current.livingPortrait.paragraphs` from `result.livingPortrait.split(/\n\n+/)`.
- **Facts**:
  - `op: "add"` → append `Fact { tags, conclusion, confidence: startConfidence ?? 0.5, n: 1, lastVerifiedISO: todayISO }` unless the tag combo + conclusion already exists (then no-op)
  - `op: "increment"` → find matching fact, `n += deltaN ?? 1`, `confidence = ewma(confidence, 0.85, 0.2)` (moving average toward 0.85 with weight 0.2), `lastVerifiedISO = todayISO`
  - `op: "adjust"` → find matching fact, set `confidence = newConfidence` directly, `lastVerifiedISO = todayISO`
- **Dream**: prepend `{ timestampISO: `${todayISO}T${HH:MM current}`, narrative: result.dreamNarrative }` to `current.dreams`
- Returns new `ParsedMemory`. Do NOT delete facts. Do NOT modify Salient Moments (those come from T2, not Reflect).

### context.ts

```typescript
import type { ParsedMemory, Fact } from "./types";

export type MemoryContext = {
  livingPortrait: string;
  topFacts: Fact[];
};

let _ctx: MemoryContext = { livingPortrait: "", topFacts: [] };

export function getMemoryContext(): MemoryContext {
  return _ctx;
}

export function setMemoryContext(memory: ParsedMemory, topN = 5): void {
  const facts = [...memory.facts]
    .sort((a, b) => b.n * b.confidence - a.n * a.confidence)
    .slice(0, topN);
  const portrait = memory.livingPortrait.paragraphs.join("\n\n");
  _ctx = { livingPortrait: portrait, topFacts: facts };
}
```
