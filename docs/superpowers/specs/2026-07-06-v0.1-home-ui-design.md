## 一句话愿景

> **屏幕上不是一个音乐播放器，是 Lyra 已经在等你。一个封面、一根光带、一句话、一个输入框——除此以外什么都没有。**

---

## 1. 设计骨相（Tenets）

### 1.1 反直觉起点

**这不是音乐播放器的界面，是一个对话界面，只是恰好用歌回复。**

设计参照系：iMessage / WeChat / ChatGPT 那种"两人在聊"的拓扑。**不是** Spotify / Apple Music / 网易云的浏览逻辑。这条一旦背叛，Sprint 1b 就白做了。

### 1.2 静默运作是产品哲学

沉淀（auto dream 提炼 facts、shared_memory 强化、季度 evolution）**全部藏在幕后**：

- ❌ 无"我今天想通了……"的 Lyra 昭告
- ❌ 无季度演化的仪式动画
- ❌ 无 facts 库 dashboard、无 confidence 进度条
- ❌ 无"你和 Lyra 认识 X 天"式统计炫耀
- ✅ 一切沉淀只沉入 `memory.md`。用户偶尔想看，才看得到

Lyra 是一个不自我表扬的老朋友。她越来越懂你，用户感受到，用户永远不会被告知。

### 1.3 视图只有一个

主视图是唯一视图。没有 tab、没有 nav、没有二级页面。Settings、memory.md 偷窥、任何"管理"操作都在这一个视图**外部**通过键盘或托盘唤起。视觉里**永远看不到 chrome**。

### 1.4 克制到 chrome 缺失

- 无播放/暂停按钮（空格键）
- 无下一首按钮（Lyra 决定，或你在输入框里说）
- 无进度条（就像你不会盯着朋友语音条的秒表）
- 无收藏/分享/评论
- 无 Settings 齿轮按钮（`Cmd+,` 唤起）
- 无搜索栏（Sprint 1b MVP 不做搜索，Sprint 1b+ 才有）
- 无"Discover"或推荐列表页面

有的只有：**你输入的位置**，和**她回你的位置**。

## 3. 元素规范

### 3.1 氛围光晕背景

全屏 `background`，无边框、无渐变边界。颜色由**当前 PAD 状态**驱动。

**PAD → HSL 映射公式**（v0.1 简化版）：

```
hue        = mix(240deg, 30deg, (P + 1) / 2)   // -1 蓝 → +1 暖橙
saturation = 20% + A * 30%                     // 唤起度越高越饱和 (20%~80%)
lightness  = 88% + D * 8%                      // 支配度越高越亮 (80%~96%)
```

再叠加**时段偏色**（`08:00` 米白、`12:00` 浅苹果绿、`18:00` 浅琥珀、`22:00` 靛蓝、`03:00` 深靛）作为基色，PAD 计算结果与基色 `mix()` 60/40。

**动画**：颜色变化用 CSS `transition: background-color 4s cubic-bezier(0.4, 0, 0.2, 1)`——慢到你几乎察觉不到在变。**绝不闪、绝不动感十足**。

### 3.2 封面

- 静态 `<img>` + `border-radius: 12px` + `box-shadow`
- **切歌时**：老封面 fade-out 到 opacity 0（600ms cubic-bezier），新封面 fade-in（600ms delay 300ms 与老的错开）
- **无 hover 效果、无点击效果、无旋转黑胶动画**
- 无封面时：占位符是**当前氛围光晕颜色的一个更深的版本**（`filter: brightness(0.85)`），不是灰色矩形

### 3.3 情绪光带（EmotionLightBand）

- 400 × 32px `<canvas>` 或 SVG
- 显示**最近 20 秒**的 PAD 采样（每秒 1 sample = 20 个点，插值成平滑曲线）
- **高度**：由 P（愉悦度）驱动，中线为 P=0，向上是正 P，向下是负 P
- **颜色**：每个采样点的色是该 PAD 通过公式的对应色，形成一条渐变彩带
- **粗细**：由 A（唤起度）驱动，A 高时线条更粗
- **动画**：每秒 1 帧，从右侧滑入新点，左侧滑出老点。**不要 60fps 更新，那太累了**

**v0.1 简化**：当前尚无真实情感 agent 输出，光带只在有 turn 后逐步"喂"数据，未有数据时展示为**一条静默的水平细线**（说明"她还在听，情绪没有波动"）。

### 3.4 曲信息（Song Info）

一行文本：`《歌名》 · 艺人`

- `《》` 是中式书名号，气质对
- 中间点是 middle dot（`·` U+00B7），不是普通句点
- 一行溢出时曲名前部截断（`text-overflow: ellipsis`），保留后缀（"…Bianche · Ludovico Einaudi"）
- 无 hover 效果、无点击效果（**用户不需要"跳转到艺人页"**——那是消费型 app 逻辑）

### 3.5 小注（Rationale Caption）

**这是 Lyra 变成一个人的关键**。

- **默认状态**：单行，最多显示 40 中文字符 / 80 英文字符，超过用省略号（`…`）截断
- **可展开**：点击（或触摸）该行 → 展开为最多 3 行完整文本
- **自动收回**：展开状态下 8 秒无交互，自动收回省略号版
- **动画**：展开/收回用 `transition: max-height 300ms ease-out`
- **字体**：italic serif（见 §2.3），字色比曲信息更淡（55% opacity）
- **无引号包裹**——直接就是那句话
- **无"Lyra: "前缀**——用户已经知道是她说的，加前缀是冗余
- **省略号是"她还有话"的信号**，不是截断
- **展开后无"点击收回"提示**——8s 自动，或再次点击

**边界情况**：
- 首屏（无 turn）时：小注展示当前 morning/dream seed 的一句极短问候，如 "*给你的早。*"
- Lyra "思考中" 时：小注展示 `…`（三个点，表示她在选歌）
- 生成型歌（豆包）：小注结尾加一句 `— 我刚为你写的。`

### 3.6 对话痕迹条（Recent Turns Trace）

- 5 个迷你封面横排，居中对齐
- 每个 12×12px，圆角 2px，间距 10px
- **默认 opacity 0.5**，hover 时（鼠标进入）该单个升到 opacity 1
- **点击**任何一个 → **播放那首歌**（不是"跳到那个 turn"——那太文档化了；是"再听一次"）
- 顺序：最左是最新，最右是最旧（左新右旧——违反 iMessage 但对齐"从当下往回看"的直觉）
- 无标签、无 tooltip、无编号——就是 5 个小点

**v0.1 简化**：如果 turn 少于 5，剩余位置留空（不是占位符）。第一次打开 app 时这条完全不显示。

### 3.7 输入框

- 视口宽度 - 80px，capsule 形状
- 背景色：`rgba(255,255,255,0.6)` 上一层玻璃质感（`backdrop-filter: blur(20px)`）
- 边框：无。仅 focused 时下方 hair-line：`box-shadow: 0 1px 0 0 rgba(0,0,0,0.15)`
- 字号 15px，占位符字色 `rgba(0,0,0,0.35)`
- **占位符文本**：`和 Lyra 说点什么…`
- **回车**发送
- **Shift+回车** 换行（多行）
- **发送后**：清空输入框，输入框保留 focus（等下一句）
- **无发送按钮**（回车即发送——克制到底）
- **无表情符号 picker、无附件、无 mic 按钮**（voice input v0.2）

## 4. 首屏与状态机

### 4.1 首屏（app 启动那一瞬间）

```
用户打开 app
  ↓
  ├─ 有 dream seed?（灵魂 agent 昨夜 dream 里种了 seed）
  │    Yes → 直接播 seed 的歌 + 用 seed 提供的小注
  │
  ├─ 无 dream seed，但是 morning 时段（首次日打开）?
  │    Yes → 灵魂 agent 现选一首 morning 曲 + 一句问候小注
  │
  └─ 别的情况（下午再次打开）
       → 保持上次退出时的状态（如果那时在放什么就继续放）
```

**从 UI 视角**：用户什么都不用做，就是**打开就有了**。Lyra 不问"你想听什么"，她已经想好了。这是"她在等你"的核心体现。

### 4.2 状态列表

| 状态 | 触发 | 视觉 |
|---|---|---|
| **cold-boot** | app 第一次启动、无 keys 无库 | 氛围色 + 中央一句 slogan（英+中）+ 输入框；无封面、无光带 |
| **cold-boot-no-keys** | 有库但未配置 provider | 同上 + 输入框下方灰字 `↳ 需要一个 API key 才能对话。⌘, 打开设置。` |
| **cold-boot-no-library** | 有 keys 但库空 | 同上 + 输入框下方灰字 `↳ 拖一个音乐文件进来开始。` |
| **playing** | 主状态 | §2 布局全套 |
| **thinking** | 用户发了输入，Lyra 在选歌但还没返回 | 封面变成一个"呼吸中的圆"（当前氛围色的一个稍深版本），小注是 `…` |
| **replaced** | 用户说"换一首" | 老封面 fade-out，`thinking` 状态 1-2s，新封面 fade-in |
| **paused** | 用户按空格 | 封面顶部盖一层 `opacity: 0.85` 半透明层，无图标（**极端克制版**）；空格再按继续 |
| **generating** | 曲库 agent 走生成车道（豆包 Seed-Music） | 封面位置显示一个缓慢旋转的**声波抽象图**（不是圆形 spinner），持续 5-15s，小注 `我在为你写一首…` |
| **proactive-pending** | v0.2 主动开口 | Tray 呼吸；主视图不变（用户不点开不弹） |
| **provider-error** | LLM 返回错误 | 小注变红字 `我说不出话了。⌘, 检查一下 key？` 30s 后归位 |
| **audio-error** | 播放失败 | 小注变灰字 `这首放不出来。换一首？` 用户按回车或说话即换 |

### 4.3 keyboard 全表

| 组合 | 动作 |
|---|---|
| **空格** | 播放 / 暂停 |
| **回车** | 发送输入 |
| **Shift+回车** | 输入框换行 |
| **Cmd+,** | 打开 Settings 模态 |
| **Cmd+K** | v0.2 打开命令面板（reflect now / rollback / clear input / ...）|
| **Esc** | 收回小注展开状态 / 关闭 Settings 模态 |
| **Cmd+Q** | 退出应用（Tauri 默认） |

**v0.1 不做**：Cmd+K 命令面板、Cmd+, 之外的任何全局快捷键。

## 5. 情绪 → 氛围色的映射细节

### 5.1 时段基色（Base Palette）

| 时段 | 色（近似） | HSL |
|---|---|---|
| 05:00-08:00（清晨） | 米白偏浅茶 | hsl(30, 15%, 92%) |
| 08:00-12:00（上午） | 温和白 | hsl(45, 10%, 94%) |
| 12:00-15:00（午后） | 浅苹果绿 | hsl(100, 12%, 91%) |
| 15:00-18:00（傍晚前） | 浅琥珀 | hsl(35, 20%, 90%) |
| 18:00-22:00（晚间） | 暖蜡烛色 | hsl(28, 25%, 88%) |
| 22:00-02:00（深夜） | 靛蓝 | hsl(230, 25%, 22%) |
| 02:00-05:00（凌晨） | 深靛蓝 | hsl(235, 30%, 18%) |

深夜时段字色/元素颜色需要反转（浅字暗底）。

### 5.2 PAD 叠加

```typescript
function ambientColor(pad: PAD, timeOfDay: Date): string {
  const base = timeBase(timeOfDay);           // HSL
  const from = padHSL(pad);                   // HSL from PAD
  return mixHSL(base, from, 0.4);             // 60% 基色, 40% PAD
}

function padHSL({ p, a, d }: PAD): [h, s, l] {
  const h = lerp(240, 30, (p + 1) / 2);       // 蓝 → 暖橙
  const s = 20 + a * 30;                      // 20-50%
  const l = 88 + d * 8;                       // 88-96%
  return [h, s, l];
}
```

### 5.3 光带线条颜色

光带上每个 sample 的颜色 = `padHSL(那一秒的 PAD)`，饱和度加 10% 让它比背景更凸出。

## 7. Sprint 1b 拆分：α（UI 壳） / β（接真数据）

### 7.1 Sprint 1b-α：UI 壳

用**假数据**跑通整个界面，让"长得对不对"这件事先锁死。

- 硬编码一首本地歌的封面
- 硬编码一句小注
- 硬编码 PAD = (0.3, -0.1, 0.2) → 光带静态波形
- 输入框接受用户输入，回车后**只**把用户话追加进痕迹条，**不**触发真 agent
- 空格键真的暂停/继续（rodio audio 已就位）
- Cmd+, 真的打开 Settings（已就位）

**验收**：`pnpm tauri dev` 打开就看到 Lyra 长这样。**审美先过关**，无其他要求。约 5-7 tasks。

### 7.2 Sprint 1b-β：接真数据

α 通过后再做。

- 情感 agent（DeepSeek 或 Zhipu）：接受输入 → 输出 PAD
- 灵魂 agent（Claude）：接受输入+PAD+Soul 状态 → 输出歌的目标画像
- 曲库 agent：目标画像 → 本地库搜歌（v0.1 无嵌入检索，就是关键词匹配+PAD 距离）
- 编排：用户回车 → thinking → 情感 → 灵魂 → 曲库 → 播放 → 记 turn → 更新 mood
- 反应捕获：behavioral 参数（listen_ms/completed/skipped）连到播放器；verbal 参数从下一次输入抽取

**验收**：spec §6.4 的三个剧本（疲惫深夜、换一首、手动 reflect）。约 8-10 tasks。

## 8. 待细化的开放问题（不阻塞 spec 通过）

1. **情绪光带的**波形是"过去 20s"还是"全 turn 30s 平滑"？前者动感强、后者克制。
2. **痕迹条点击**播放那首歌——是从头放还是接着放？（我倾向从头）
3. **首屏 cold-boot** slogan 的字号和布局：hero-style 大字，还是低调居中细字？
4. **深夜模式**（22:00 后）的字色反转细节：全反转还是仅背景变暗其他不变？
5. **thinking 状态**的呼吸圆——直径、颜色、频率？
6. **paused 状态**是"半透明遮罩无图标"还是加一个极细的暂停图标？现在写的是无图标版，你确认。

上面 6 条 spec 里我给了默认值。实现时如果发现哪条不对，可以在 review 里翻案。
