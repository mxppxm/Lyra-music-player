# 锁定播放文案：越听越深的心理旁白

日期：2026-08-12  
状态：已定稿

## 问题

锁定循环每次重生 Companion `rationale`（小纸条）时，brief 把合法切入点写成「编曲细节 / 人声气息 / 某句歌词意象 / …」，并禁止复述情绪标签。

结果是：遍数在涨，模型为了「换角度」去拆歌、拆歌词——用户已经主动停在这首里，却像还在被做音乐分析。

需要的不是换歌学角度，而是：**为什么还停在这、心里可能在发生什么；且越听越深，高遍数可偶尔发问。**

## 目标

1. 锁定全程心理向：朋友旁白口吻，轻洞察，不诊断、不术语
2. 深度随 `lockPlayCount` 加码（不是同级换角度）
3. 发问策略：先修辞问 → 高遍数才偶尔真问（可回，但仍只是小纸条文本）
4. **只改文案路径**（brief / 测试）；不动锁定状态机、UI、选歌、原生队列

## 非目标

- 不为真问新增交互协议或独立「回答锁定问题」模式
- 不改 `moodLocked`、每日心情总结、收藏/推荐权重
- 不拆独立锁定 Agent / 独立 system prompt（首版只改锁定 brief；若仍飘再升级）
- 不改小纸条长度产品语义（仍短；深也不注水）

## 口吻与内容

- **口吻**：朋友式旁白（懂你的人轻声一句）
- **内容**：轻心理洞察——动机/需求/卡住或松动（沉浸、确认、回避、发泄等），用人话，不贴标签式诊断
- **禁写**：拆歌词/编曲当主菜；复述情绪 labels；同义改写旧句；咨询腔/术语

歌本身仍可作为**极轻**的锚（歌名/整体氛围一笔带过），但主菜必须是「停住」与心里变化。

## 深度轨迹

| 遍数 | 深度 | 写什么 | 发问 |
|------|------|--------|------|
| 1–2 | 轻触 | 为什么会锁住、想停在这的感觉 | 禁止发问 |
| 3–4 | 下探 | 可能在确认/回避什么、反复碰哪一块 | 可偶发修辞问 |
| 5–7 | 深 | 「还在转」本身说明了什么；心里可能在松/在硬 | 修辞问为主 |
| 8+ | 顶 | 少而重的一刀；可偶尔抛一个可回的真问 | 真问约每 3–4 遍最多一次；近期已问过则禁止再问 |

真问出现时：用户若在输入框接话，沿用现有「新输入 → 退出锁定 → 正常对话/选歌」，不另开协议。

## 实现（文案 only）

### 改动面

1. **`packages/core/src/agents/CompanionAgent.ts` — `buildBrief` 锁定分支**  
   - 删除「编曲细节 / 人声气息 / 某句歌词意象 / 时间氛围 / 和她的关系」这类切入点列表  
   - 改为注入心理深度指引 + 禁写 + 发问规则（按遍数）  
   - 保留：固定 `song_id`、禁用近期 `lockRecentRationales`、禁止同义改写

2. **`lockDepthGuidance(n: number): string`**（同文件或紧邻模块）  
   - 集中阶段文案，便于单测断言「第 N 遍注入了什么」

3. **测试 `CompanionAgent.test.ts`**  
   - 低遍数：含轻触指引、不含真问许可  
   - 中遍数：含更深动机/修辞问许可  
   - 高遍数：含真问许可（及「近期已问过则别再问」若写入 brief）  
   - 旧「编曲/歌词意象」切入点字符串不再出现

### 不改

- Orchestrator 锁定循环 / `fillTrackLockRationale` / `lockRecentRationales` 收集逻辑（除非 brief API 无需动）
- UI、`TrackLockButton`、prefetch / native queue
- `COMPANION_SYSTEM_PROMPT` 全局规则（锁定专用约束放在 brief 覆盖即可；避免误伤普通选歌小注）

### 数据流（不变）

```
onSongComplete (locked)
  → playCount++
  → fillTrackLockRationale(lockPlayCount, recentRationales)
  → companion.choose({ lockPlayCount, lockRecentRationales, … })
  → patch rationale → SmallNote
```

仅 `buildBrief` 在 `lockPlayCount` 分支输出的指令内容变化。

## 风险

| 风险 | 缓解 |
|------|------|
| 仍滑回拆歌 | brief 硬禁 + 单测断言不再出现旧切入点措辞 |
| 咨询腔 | 明确禁止术语/诊断；强调朋友旁白 |
| 真问太密 | 8+ 且「近期已问过别再问」；真问仅文本 |
| 越写越长 | 仍约束短小注；深 = 更准，不是更长 |

## 验收

- 锁定 1–2 遍：心理轻触，无发问
- 3–7 遍：更深动机/变化；可有修辞问；不以歌词分析为主
- 8+ 遍：可偶发真问；用户接话仍退出锁定
- 单测：brief 随遍数注入对应深度；旧拆歌切入点消失

## 后续（非本版）

若改 brief 后模型仍常拆歌或咨询腔：再考虑独立锁定 system prompt（设计讨论中的方案 B）。
